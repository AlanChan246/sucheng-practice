## 功能證據

- v1 → v2：保留總成績、最佳紀錄及解鎖；不捏造逐字進度。未知版本拒絕直接遷移，無效數字正規化。
- 快照：回饋、選字選項、提示和默寫已收起狀態可持續儲存。
- 首次錯誤立即寫入；有足夠題目時隔兩題再試，最多加入五題；重試不灌水首次成績，完成結算具冪等性。
- 19/25 不通關，20/25 通關；既有通關及最高紀錄不倒退。
- 三次不同題組、至少相隔一天的獨立輸入才記得穩；提示、選字、同組再試排除。答錯或使用提示後重新累積確認。
- 所有短課例字及教學全碼對照打包字庫。
- Happy DOM 實際觸發元件事件：首次 A/B 觸控、滿碼自動作答、下一題焦點、重載回饋、錯誤解釋與按鍵描邊、選字數字快捷鍵、默寫再看提示、小課／關卡／空進度入口、儲存失敗提示。
- 默寫選定 1.8 秒後確實自動收起，並於下一題保留節奏選擇；避免每換一題都要重新設定。重新進入此頁仍預設手動。

Happy DOM 是記憶體內 DOM，不會呈現 CSS，也不會開啟網站。這些結果不能證明手機 IME、滾動位置、實際觸控或畫面排版通過。

## Persona 走查狀態

### A：完全不懂速成的小五學生

程式與 DOM 測試已覆蓋「首次 A/B → 小課 → 三題 → 回饋」。第一步只有日／月兩鍵；答錯保留輸入並指向首尾。IAB已實走首次錯答／重試／成功／第一課三題／完成，仍未量測真人學生理解或持續使用意願。

原有走查計畫（最新已執行與界限見catalog核對表）：首次造訪 → 故意打錯 → 重試 → 第一課 → 答錯一題 → 看解釋 → 完成 → 重溫。確認在手機上無需先懂導覽、第一次成功不需要找按鈕。

### B：已懂少量速成的中學生／成人

程式已提供直接練習、5 題入口、實體鍵盤、續題、弱鍵和錯題重溫；DOM 測試覆蓋自動送出及選字快捷鍵。IAB已核對連續A/B/AB輸入、下一題焦點、數字選字、reload保留回饋；真實手機作答速度仍未量測。

原有走查計畫（最新已執行與界限見catalog核對表）：略過新手 → 三種模式 → 中途離開／返回 → 通關 → 足跡弱鍵 → 重練。確認不被教學強制攔截，能只用鍵盤連續作答。
